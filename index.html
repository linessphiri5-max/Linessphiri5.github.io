LINESS PHIRI'S DATA ANALYST PORTFOLIO

Turning Raw Data into Decisions

I am a data analyst focused on turning raw data into clear, usable insights. My process moves through the full pipeline, cleaning and structuring data in Python and Excel, querying and analyzing it in SQL, and building dashboards in Power BI that make findings easy to act on. I am always learning, always building, and always looking to work on projects that challenge me to grow.

TOOLS I USE

PYTHON

Python is one of my core tools for data cleaning, transformation, and exploratory analysis, using libraries such as pandas, matplotlib, seaborn and numpy to handle everything from missing data to feature engineering.

SQL

SQL is how I query, join, and analyze structured data to answer specific business questions directly at the data layer. I work with PostgreSQL and MySQL, using aggregations, window functions, and subqueries to segment data and surface patterns that inform decisions.

POWER BI

Power BI is where I turn analysis into interactive dashboards, covering data modeling and DAX measures.

EXCEL

Excel is my go-to for quick analysis, pivot tables, and formula-driven calculations. I use it for data cleaning, summarizing trends, and building simple reports.
